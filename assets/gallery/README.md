# Folder Galeri Foto Pengantin

Simpan foto-foto pengantin di folder ini.

## Cara Pakai

1. Masukkan foto ke folder ini dengan nama sesuai urutan:
   - photo-1.jpg
   - photo-2.jpg
   - photo-3.jpg
   - photo-4.jpg
   - photo-5.jpg
   - photo-6.jpg

2. Atau, ubah nama file di data.js pada bagian galeri.foto

## Tips
- Format yang didukung: .jpg, .jpeg, .png, .webp
- Ukuran ideal: Lebar minimal 800px
- Foto yang belum ada akan tampil sebagai placeholder elegan
